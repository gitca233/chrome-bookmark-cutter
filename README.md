# Chrome 书签文件夹裁剪器

一个纯前端单文件的 Chrome 书签裁剪工具：选择 Chrome 导出的 `bookmarks.html`，勾选要保留的文件夹，导出裁剪后的全新书签文件，可直接导回 Chrome。

## 功能特性

- 解析 Chrome「书签管理器 → 导出书签」生成的 `bookmarks.html`
- 目录树勾选操作：全选 / 全不选 / 只选顶层文件夹
- 两种导出模式：
  - **导出选中的文件夹**：导出勾选文件夹及其全部子内容，完整保留层级
  - **导出（不含子文件夹）**：只导出勾选文件夹内的直属书签，跳过所有下级文件夹
- 未勾选的父级文件夹自动跳过，勾选的子文件夹会提升为顶层导出
- 导出前可自定义文件名（默认 `chrome-bookmarks-selected.html`，自动补 `.html` 后缀）
- 导出文件完全遵循 Chrome Bookmark HTML 标准结构，可直接在 Chrome「书签管理器 → 导入书签」中导入

## 使用方式

1. 打开页面（本地双击 `index.html`，或访问在线部署地址）
2. 点击「选择 bookmarks.html」，选择 Chrome 导出的书签文件
3. 在目录树中勾选需要保留的文件夹
4. 点击导出按钮，输入文件名后保存
5. 在 Chrome 书签管理器中导入生成的 HTML 文件

## 隐私

所有处理完全在浏览器本地完成，书签数据不会上传到任何服务器。

## 部署

项目为纯静态单页（`index.html` 即完整应用），无需构建，可直接部署到 Vercel / GitHub Pages 等任意静态托管服务：

- **Vercel**：导入本仓库，框架预设选择 `Other`，无需构建命令与配置，直接 Deploy
- **本地**：直接双击 `index.html` 即可使用

## 技术说明

- 零依赖、零构建，单文件 HTML + 原生 JavaScript
- 复用 Chrome 官方的 NETSCAPE Bookmark HTML 格式，导入器按行识别 `<DT><H3>`（文件夹）与 `<DT><A>`（书签）结构
